# Manny Wenas colour palette

Agreed on 20 October 2026 for Manny Wenas products and mannywenas.com. The existing MW logo remains the source for the primary purple. Use these colours as shared design tokens; do not recolour the logo or change SEO scoring to suit the interface.

| Role | Hex | Use |
| --- | --- | --- |
| Primary | `#721E97` | MW logo, primary actions, links and key brand text |
| Selected background | `#F1E6F6` | Active navigation and restrained highlights |
| Page background | `#F5F4F7` | Admin and site page canvas |
| Surface | `#FFFFFF` | Cards, forms and navigation surface |
| Main text | `#27212B` | Headings and body copy |
| Secondary text | `#625A65` | Descriptions and supporting information |
| Subtle border | `#E6E0E9` | Card and section boundaries |

Use white text on the primary purple for solid buttons. Keep important text and controls readable without relying on colour alone. The setup screen uses the MW mark with the product name and “Write it your way.” as one visual lockup, while keeping the tagline as selectable text.
